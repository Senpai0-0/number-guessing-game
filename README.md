# 🎯 Number Guessing Game

A simple console-based number guessing game written in Python.

## 📖 How It Works
The program randomly picks a number between 1 and 100.
The player tries to guess it, and the program gives hints
("too high" / "too low") until the correct number is found.

## 🚀 How to Run
```bash
python main.py
```

## 🛠️ Built With
- Python 3

## 📌 Features
- Random number generation
- Limited number of attempts
- Input validation
